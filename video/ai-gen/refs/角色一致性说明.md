# 角色一致性说明 · 三段视频共用

> 视频生成最容易翻车的就是**换人**。所有提示词里的角色描述都从这里抄，
> 跑任何一段都先确认这段描述在提示词里（或挂了参考图）。

---

## 一、外观锚点（提示词里必须有的要素）

| 部位 | 描述 | 丢掉会怎样 |
|---|---|---|
| 体型 | **Q版 / chibi**，头身比约 1:2 | 变成写实少女就全毁 |
| 发型 | 蓝色**渐变**长发（深蓝发根 → 发梢偏浅蓝），**双马尾** | 认不出是她 |
| 呆毛 | 头顶一根**卷曲的呆毛**（月牙形） | V3 直接没法做 |
| 发饰 | 白色荷叶边**女仆发带** | 少了女仆感 |
| 上衣 | 深蓝色连衣裙（袖口有金色小装饰） | — |
| 围裙 | **白色围裙，上面绣一只小鲸鱼** | ★识别度核心 |
| 尾巴 | 身后一条**蓝色鲸鱼尾巴** | ★识别度核心（她是鲸鱼娘） |
| 眼睛 | 大大的蓝色眼睛 | — |
| 腮红 | 腮红明显 | 少了软萌感 |
| 渲染 | 可爱贴纸质感 / 棉花糖质感 | 偏写实就废 |

**一句话版本**（提示词里直接用）：

> Q版chibi动漫少女，蓝色渐变长发+双马尾+头顶一根卷曲呆毛，白色女仆发带，
> 深蓝连衣裙配白色围裙（围裙绣小鲸鱼），身后蓝色鲸鱼尾巴，大蓝眼睛+明显腮红，
> 可爱贴纸质感。

---

## 二、风格锚点

- **日系动画**，不是 3D 渲染，不是真人
- **贴纸 / 棉花糖质感**：边缘干净、色彩平、有点厚度感
- **高明度、高饱和**：不要暗黑、不要写实光影
- 无文字、无水印、无 logo

---

## 三、参考图怎么用

| 文件 | 用法 |
|---|---|
| `character_sheet_透明底.png` | **首选**。透明底全身立绘，图生视频挂这张当角色参考 |
| `ref_v1_全身站姿_浅蓝底.png` | 备选参考（原图带浅蓝底）。即梦对带底图的参考接受度更高 |
| `ref_v2_指脸害羞_近景.png` | V2 专用参考（表情是「指脸害羞」，你要的「呆萌」是另一种——提示词里已写） |
| `ref_球内首帧_呆毛.png` | **V3 专用首帧**，构图锁定 |

## 四、已知翻车点（定妆 mp4 踩过的坑）

1. **星空底那段难抠**（ref_v1_比心）——当参考可以，别当生成底
2. **「AI生成」角标**在左上角——生成时主体放中间，我后期裁
3. **写实倾向**：即梦偶尔会往写实跑，一旦发生就加「Q版 chibi 贴纸质感」+ 挂参考图
4. **手崩**：Q版手最容易崩。手部动作写「轻轻拍一下」这种简单动作，别写复杂手势
5. **多动作容易乱**：V1 的「探头→跑→停」如果翻车，拆成两段生成（先跑，再停步），我剪在一起

## 五、三段的角色一致性自查表

生成完每一段，对着 `character_sheet_透明底.png` 逐项打勾：

- [ ] 蓝色渐变发 + 双马尾
- [ ] 头顶卷曲呆毛
- [ ] 白色女仆发带
- [ ] 白围裙 + 小鲸鱼刺绣
- [ ] 蓝色鲸鱼尾
- [ ] 大蓝眼 + 腮红
- [ ] Q版比例（不是少女比例）
- [ ] 贴纸质感（不是 3D 写实）

**丢 3 项以上 → 重跑。**
