# video/ai-gen/ · AI 视频生成工作区

> 这个文件夹是**你去跑视频生成的工作区**。我（混剪侧）只负责把生成好的片子抠像、对轴、剪进正片。
> 分镜总表见 `docs/B站介绍视频_分镜脚本_v1_2026-10-22.md`；开场拆解见画布《B站视频开场_实现拆解》。

---

## 一、结论：要生成 3 段

| 编号 | 名称 | 覆盖分镜 | 目标时长 | 画幅 | 生成方式 | 优先级 |
|---|---|---|---|---|---|---|
| **V1** | 踏浪入场 | F1 探头 + F2 踏浪跑 | 5~7s | 16:9 | 图生视频（全身贴纸做参考） | **必须** |
| **V2** | 呆萌停步 | F3 呆萌特写 | 3~5s | 16:9 | 图生视频（近景参考） | 推荐 |
| **V3** | 球内呆毛 | F4 终态 + F5 拍回 | 5s | 16:9 | **图生视频（球参考图做首帧）** | **必须** |

**为什么是这 3 段**：其余节拍（切海报、球展开、对话框自我介绍）都能用贴纸 + ffmpeg 做，
只有这 3 段需要**有机的运动**——跑步循环、表情反应、手部拍打——贴纸做不出来。

**不生成**（我用 ffmpeg 做，0 积分）：
- F6 主背景切海报 → xfade 0.6s
- F7 球展开 → 球放大淡出 ∥ 对话框淡入
- F8 害羞自我介绍 → 对话框逐字 + 害羞贴纸（ref_v2 那张指脸帧正好）

## 二、怎么用这个工作区

1. **看提示词**：`prompts/V1~V3` 三个文件，每个都写好了中文词（即梦用）和英文词（可灵/Vidu/Runway 用）
2. **挂参考图**：`refs/` 里有 4 张图，每段视频用哪张在提示词文件里写明了
3. **去生成**：推荐**即梦**（你的定妆 mp4 就是它出的，风格血统一致），备选可灵、Vidu
4. **丢回这里**：成片按 `output/命名规范.txt` 的名字放进 `output/`
5. **喊我**：我来抠像、对轴、混剪进正片

## 四、生成参数速查

- **画幅**：全部 **16:9**（正片是 1080p 横版）
- **时长**：即梦一般 5s / 10s 两档 → V1 要跑满动作可选 10s，V2 选 5s 只用前 3 秒，V3 选 5s
- **水印**：即梦会带「AI生成」角标 → 生成时让它把主体放在画面中央，我后期裁切掉
- **背景**：V1/V2 尽量**纯色或简单渐变底**（好抠像）；V3 跟首帧一致（深色）就行
- **别做的事**：不要加字幕、不要加转场、不要 4K（浪费，1080p 够用）

## 五、output/ 命名规范

生成好的片子丢进来，命名：

```
V1_踏浪入场.mp4
V2_呆萌停步.mp4
V3_球内呆毛.mp4
```

同一个版本不满意重跑的，加后缀 `V1_踏浪入场_v2.mp4`。**每个编号保留你满意的那一条**（最新版不带后缀或告诉我用哪版）。

## 六、每段的验收标准

**V1**：
- [ ] 角色长得像 refs 里的她（蓝发、女仆装、围裙小鲸鱼、鲸鱼尾、呆毛）
- [ ] 运动方向是**从右往左**（反了没关系，我水平翻转）
- [ ] 脚下有浪花/水花
- [ ] 背景简单、和角色分离得开（好抠）
- [ ] 5 秒内完成「出现 → 跑 → 停」或至少「跑」这一下

**V2**：
- [ ] 表情读起来是「呆萌 / 懵」，不是「笑」也不是「哭」
- [ ] 有一次眨眼或歪头的小动作
- [ ] 半身构图，脸在画面上三分之一

**V3**（最重要的一段）：
- [ ] 首帧和你给的球参考图几乎一样（球内有她、呆毛露外）
- [ ] 呆毛能明显看出「晃两下」
- [ ] 「手拍回」这个动作能看清（或至少呆毛「嗖地缩回」）
- [ ] 球的质感保持玻璃感，不要变形

## 七、翻车急救

| 症状 | 怎么办 |
|---|---|
| 跑步像在太空飘 | 提示词里加「脚踩在水面上，脚边有白色浪花，步伐轻快有弹性」 |
| 脸崩了 / 换人了 | 用**图生视频**别用文生视频，首帧挂 `character_sheet_透明底.png` 或全身参考图 |
| 呆毛消失了 | 提示词强调「头顶有一根卷曲的呆毛」；V3 用首帧图就不会丢 |
| 手拍不出来 | 降级：只做「呆毛晃两下然后缩回球内」，手的动作我后期用贴纸补 |
| 背景太花没法抠 | 要求「纯色背景 / 渐变背景 / 纯色影棚背景」，或者你告诉我，我用别的办法抠 |
| 即梦风格偏写实 | 加「Q版 chibi、日系动画、贴纸质感、棉花糖渲染」并挂参考图 |
