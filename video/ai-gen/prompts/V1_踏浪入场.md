# V1 · 踏浪入场

> 覆盖分镜：**F1 右侧探头 + F2 踏浪跑向左**
> 优先级：**必须**（跑步是贴纸做不出来的）
> 推荐工具：即梦「图生视频」· 备选可灵 / Vidu

---

## 参数

| 项 | 值 |
|---|---|
| 画幅 | **16:9**（横版） |
| 时长 | **5s**（即梦）；若想跑满「探头→跑→停」完整节拍，选 **10s** |
| 生成方式 | **图生视频**，参考图挂 `refs/ref_v1_全身站姿_浅蓝底.png` |
| 背景要求 | 纯色或简单渐变（浅蓝/浅青），**方便我抠像** |
| 水印 | 主体放画面中央，角落水印我裁 |

## 动作节拍（生成时心里有数）

| 时间 | 动作 | 画面 |
|---|---|---|
| 0~1s | 右缘探头 | 她从画面右缘探出头/半个身子，张望 |
| 1~4s | 踏浪向左 | 轻快小跑穿过海面，脚下浪花，头发裙摆飘 |
| 4~5s | 停步 | 在左侧停下，微微前倾，抬头看镜头 |

10s 版可以把「跑」拉长、加一次回头看。

## 翻车急救

| 症状 | 换这个说法 |
|---|---|
| 像在太空飘、没踩水感 | 加「脚踩在水面上，脚边有白色浪花，步伐轻快有弹性」 |
| 方向反了（从左往右跑） | 没关系，**我后期水平翻转**；或改成「向画面左侧跑去」 |
| 脸崩了 | 改用图生视频 + 挂 `character_sheet_透明底.png` |
| 背景太花没法抠 | 加「纯色浅蓝色背景，像影棚背景纸」 |
| 跑步腿糊成一团 | 降低动作幅度：「小步快跑」而不是「全力奔跑」；或缩短到「走两步跳一下」 |
| 风格偏写实 | 加「Q版 chibi，日系动画，贴纸质感」并挂参考图 |

## 验收标准

- [ ] 角色像 refs 里的她（蓝发、女仆装、围裙小鲸鱼、鲸鱼尾、呆毛）
- [ ] 运动方向从右往左（或告诉我，我翻转）
- [ ] 脚下有浪花
- [ ] 背景和角色分离得开（我好抠）
- [ ] 能读出「探头 → 跑 → 停」或至少「跑」这一下
