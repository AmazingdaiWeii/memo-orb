## 动作节拍

| 时间 | 动作 | 看点 |
|---|---|---|
| 0~1s | 保持首帧构图 | 球内有她、呆毛露外——这就是参考图状态 |
| 1~2s | 眨眼 | 让画面「活」起来 |
| 2~3.5s | 呆毛左右摇摆两下 | **喜感来源①**：明明缩进球里了，呆毛还不听话 |
| 3.5~4.5s | 手从球顶开口伸出，拍回呆毛 | **喜感来源②**：名场面 |
| 4.5~5s | 手收回，她眯眼微笑 | 收尾得意 |

## 翻车急救

| 症状 | 换这个说法 |
|---|---|
| 球变形/消失 | 负面词加「球变形，球消失」；正向加「保持首帧构图完全不变，只有呆毛和手在动」 |
| 她跑出球了 | 加「她始终待在玻璃球内部」 |
| 呆毛没了 | 用首帧图就不会丢；或强调「球外的那根呆毛」 |
| 手拍不出来 | **降级用简化版**（呆毛自己缩回），手的动作我后期贴纸补 |
| 镜头乱动 | 加「固定镜头，正面平视，无运镜」 |
| 玻璃质感没了 | 加「保持玻璃球的透明质感和高光反光」 |

## 验收标准

- [ ] 首帧和 `ref_球内首帧_呆毛.png` 几乎一样（球内有她、呆毛露外）
