> 优先级：**推荐**（贴纸推近也能凑合，但生成的表情活得多）
> 推荐工具：即梦「图生视频」· 备选可灵 / Vidu

---

## 参数

| 项 | 值 |
|---|---|
| 画幅 | **16:9** |
| 时长 | **3~5s**（即梦最少 5s 就选 5s，只用前 3 秒） |
| 生成方式 | **图生视频**，参考图挂 `refs/ref_v2_指脸害羞_近景.png` |
| 构图 | 半身/中近景，脸在画面上三分之一 |
| 背景要求 | 简单渐变或纯色（好抠） |

## 动作节拍

| 时间 | 动作 | 表情 |
|---|---|---|
| 0~1s | 停步、微喘 | 平静 → 微微回神 |
| 1~2s | 眨眼 | 无辜 |
| 2~3s | 歪头 + 嘴张成小圆 | **呆萌困惑（核心）** |
| 3~5s | 保持/轻微晃动 | 定格在呆萌上 |

⚠ 核心是**「懵」**，不是「笑」也不是「哭」。如果出来的是笑，重跑时强调「困惑、发愣、呆住」。

---

## 翻车急救

| 症状 | 换这个说法 |
|---|---|
| 表情太开心/在笑 | 加「困惑、发愣、呆住、表情空白」，删掉「可爱微笑」类的词 |
| 表情太凶/严肃 | 加「软萌、无辜、无害」 |
| 脸崩了 | 挂 `ref_v2_指脸害羞_近景.png` 做图生视频首帧 |
| 变成全身了 | 强调「半身特写，脸部占画面三分之一以上」 |
| 没有小动作 | 加「轻轻歪头，眨眼一次」 |
