## 怎么用

- **App / 产品内头像**：用 `头像_512.png` 或 `圆形_512.png`
- **社交平台方形头像**：`头像_256.png`
- **列表 / 小图标**：`头像_128.png`
- **要动的头像**（B站大会员 GIF 头像、直播间、表情）：`动图/轻量版/`（体积安全）
- **要动又要清晰**：`动图/`（256px，注意平台大小限制）

V3 的两款用法不同：**方形=球内脸部特写**（四角是球内浅蓝底，干净），**圆形=完整圆章**（带章体边缘，像实体挂件）。看场景挑。

## 取帧与裁切的依据

- V1：用亮度阈值检测角色包围盒，发现 n=72 时角色中心 x=950 正好在画面中线——就用这帧做头像。裁 720px 上半身，保留踏浪的动势。
- V2：角色本就居中，脸在 (960,490) 附近，裁 800px 脸部特写。n=70 的「瞪眼小嘴」是三帧里最呆萌的。
- V3：圆章检测稳定（圆心 894,596，直径 ~945px）。方形取内切 700px（避开深灰桌面底），圆形取完整 952px 章体。

动图段落：V1 取 2.29s 起 2.2s（跑→停），V2 取 1.4s 起 2.6s（闭眼→呆萌），V3 取 1.6s 起 3.0s（惊讶→抬手拍→收）。
